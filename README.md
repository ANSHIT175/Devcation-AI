# 🚀 Devcation – AI Powered Student Opportunity Platform

## 📌 Problem Statement

Students struggle to discover relevant opportunities, guidance, and resources due to scattered platforms and lack of personalization.

## 💡 Solution

Devcation is a centralized platform that provides personalized recommendations for internships, hackathons, and learning resources using AI-based logic.

## ✨ Features

* 🔍 Smart opportunity search
* 🤖 Personalized recommendations
* 📊 User interest-based filtering
* 📚 Curated learning resources
